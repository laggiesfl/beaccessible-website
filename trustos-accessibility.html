TrustOS Accessibility Statement

Phase 1 consolidation demonstration

Return to TrustOS

Current status: designed toward WCAG 2.2 Level AA. Formal conformance has not yet been established.

Accessibility measures

  • Semantic page regions and heading structure.
  • Skip links and clearly visible keyboard focus.
  • Native buttons and links with non-colour-only states.
  • High-contrast text and controls.
  • Reduced-motion support.
  • Descriptive titles for embedded modules and full-page alternatives.

Known limitations

  • The embedded TrustOps Core and GrantFlow prototypes retain their existing accessibility limitations.
  • Nested scrolling inside an embedded module may be less convenient for some keyboard, screen magnification, and mobile users; each module can also be opened as a full page.
  • Independent screen-reader testing and testing with disabled users are pending.
  • No third-party accessibility certification is claimed.

Feedback and support

If you encounter a barrier, email hello@beaccessible.co.za. Please include the page or module, what you were trying to do, and the assistive technology or browser used if you are comfortable sharing it.

Assessment approach

Phase 1 uses automated structural checks and keyboard-oriented regression checks. A production release requires manual keyboard review, screen-reader testing, zoom and reflow testing, and disabled-user evaluation.
